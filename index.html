Yükleme aracı / Upload tool

"Kagittan Fabrika Yukleyici", kanalın kendi videolarını kanalın kendi YouTube hesabına yükleyen, sadece kanal sahibinin kullandığı özel bir araçtır. YouTube API Hizmetlerini yalnızca video yüklemek ve kanal adını/video durumunu okumak için kullanır. Başka kullanıcıların verisine erişmez.

English: "Kagittan Fabrika Yukleyici" is a private tool used only by the owner of the Kağıttan Fabrika channel. It uses the YouTube API Services solely to upload the channel's own videos to the channel and to read the channel name and upload status. It does not access any other user's data.
