Gizlilik Politikası / Privacy Policy

Son güncelleme / Last updated: 1 Ekim 2026 / October 1, 2026

1. Kapsam / Scope

Bu politika, Kağıttan Fabrika kanalının sahibi tarafından kullanılan "Kagittan Fabrika Yukleyici" yükleme aracını kapsar. Araç yalnızca kanal sahibi tarafından, kanal sahibinin kendi YouTube hesabıyla kullanılır.

This policy covers "Kagittan Fabrika Yukleyici", an upload tool used only by the owner of the Kağıttan Fabrika channel, with the owner's own YouTube account.

2. YouTube API Hizmetleri / YouTube API Services

Araç YouTube API Hizmetlerini kullanır. Aracı kullanarak YouTube Hizmet Şartları'nı kabul etmiş olursunuz. Google'ın verileri nasıl işlediği için: Google Gizlilik Politikası.

This tool uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

3. Erişilen ve saklanan veriler / Data accessed and stored

  • Kanal sahibinin verdiği OAuth erişim/yenileme anahtarı (kapsamlar: youtube.upload, youtube.readonly). Kanal sahibinin özel sunucusunda, yalnızca sahibinin okuyabileceği bir dosyada saklanır.
  • Kanalın adı ve kimliği, yüklenen videoların kimliği ve yükleme durumu.
  • Başka hiçbir kullanıcının verisine erişilmez; izleyici verisi toplanmaz.

The OAuth access/refresh token granted by the channel owner (scopes youtube.upload, youtube.readonly), stored in an owner-only file on the owner's private server; the channel name and ID; the IDs and upload status of uploaded videos. No other user's data is accessed and no viewer data is collected.

4. Kullanım / Use

Veriler yalnızca kanalın kendi videolarını kanala yüklemek ve yüklemenin sonucunu kontrol etmek için kullanılır.

The data is used only to upload the channel's own videos to the channel and to check the result.

5. Paylaşım / Sharing

Veriler satılmaz, üçüncü taraflarla paylaşılmaz ve reklam amacıyla kullanılmaz (YouTube/Google'a yapılan API çağrıları hariç).

The data is not sold, shared with third parties or used for advertising (other than the API calls made to YouTube/Google themselves).

6. Saklama ve silme / Retention and deletion

Anahtar, araç kullanıldığı sürece saklanır ve kanal sahibi tarafından istendiği an silinir. Erişim her zaman Google hesap izinleri sayfasından geri alınabilir; geri alındığında araç hiçbir veriye erişemez.

The token is kept while the tool is in use and deleted on the owner's request. Access can be revoked at any time at Google account permissions; after revocation the tool cannot access any data.
